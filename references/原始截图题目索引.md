# 初始课程主题索引

> 根据早期课程主题笔记整理。以下是语义归一的主题索引，并非逐字记录。

## 期权部分

1. 盈亏平衡、溢价、杠杆机制。
2. 期权价值构成、行权、损益图、合约乘数、合约规模。
3. Greeks（Delta / Delta 中性 / 对冲 / 有效杠杆；Theta / Gamma / Vega / Gamma Squeeze；到期日及行权价的影响；Rho；IV / IV 倾斜 / IV vs 历史波动率；期限 IV 与杠杆、风险与超额收益）。
4. 正股股息和拆股对期权的影响。
5. Black–Scholes 模型（选学）。
6. 策略：Long Call / Put / LEAPS；Naked Sell Put / Cash-Secured Put / Naked Sell Call / Covered Call；Protective Put / Collar；Long Strangle / Long Straddle；Bull Call / Bear Put / Diagonal；Bear Call / Bull Put / Iron Condor；Roll up / Roll over。
7. 组合期权保证金风控规则。
8. 杠杆损耗及成因、为什么谨慎交易短期期权。
9. 期权与财报。
10. 到期日和行权价怎么选。
11. 期权与期货的区别。
12. VIX、隐含波动率及 VIX 指示意义。
13. 期权复利。
14. 投资哲学：安全边际、确定性、杠杆。

## 第三部分（选学）宏观

1. 一般均衡：产品 / 货币 / 劳动力 / 资本市场。
2. 财政政策与货币政策。
3. 经济增长：内生增长理论。
4. 经济周期。
5. 去杠杆与软着陆。
6. 货币乘数。
7. 信用创造与收缩。
8. MV=PY。
9. 西方经济学：古典、自由主义及理论流派。
10. 大萧条成因、影响与走出危机。

## 整理原则

结构和先修关系经过重排，但**不删除截图项目**；宏观部分单独选学，不强制让期权主线变成宏观教材。截图上色彩/新增标注主要表明旧笔记修订痕迹，不等于知识点轻重。
