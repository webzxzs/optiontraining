# Options Training｜期权投资与交易自学教材

一套中文期权自学教材，覆盖**长期股票投资中的期权应用**与**专业期权交易的基础知识**。课程以可复算的算例、风险边界和独立判断为核心，不以策略复杂度或高胜率作为盈利依据。

## 快速开始

- **[全部23节课程目录](课程/目录.md)**：按学习路线浏览讲义、习题、原有收益图及新增的公式速读图。
- **[课程总纲与学习路径](课程总纲.md)**：查看每节课的能力目标与先修关系。
- **[L01｜期权本质、盈亏平衡与杠杆](课程/L01-期权本质-盈亏平衡-杠杆/讲义.md)**：建议从这一节开始。
- **[L23｜六种投资表达的综合比较](课程/L23-六种投资策略综合比较/讲义.md)**：贯通股票、期权和不交易决策。

## 学习路线

| 路线 | 已编写课次 | 学习重点 |
|---|---|---|
| A · 共同基础 | L01–L09 | 合约结构、到期与途中盈亏、Greeks、IV、期权链与交易价值 |
| B · 长期投资应用 | L10–L12、L14、L17–L20、L22–L23 | 正股与期权的选择、价差、保护策略、保证金、执行和风险预算 |
| C · 专业交易基础 | L13、L15–L16、L21 | 事件波动、跨期价差、铁鹰、VIX及相关产品 |

建议先学习A，再学习B，随后按需进入C。风险控制内容应提前交叉阅读，不必等到某一路线结业。

## 使用边界

本项目供学习与研究，不构成投资建议。交易前请依据最新的 **OCC、Cboe、FINRA** 等官方文件及适用券商规则，独立确认期权合约、行权指派、保证金、流动性和交割安排。到期损益不等于持有期间的报价变化，也不能代表真实账户的资金需求。
